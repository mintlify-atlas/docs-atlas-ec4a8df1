lailai's Home is a personal documentation website built with [Docusaurus](https://docusaurus.io) — a static site generator developed by Meta — and deployed on [GitHub Pages](https://pages.github.com). It serves as a central hub for technical notes, algorithm contest material, project documentation, and blog posts.

Before settling on Docusaurus, lailai tried platforms like CSDN, 博客园, WordPress, and Hexo. The main problem with traditional blog platforms was their timeline-based structure, which is poorly suited to organizing reference material. Docusaurus's tree-structured documentation layout fits the need to organize and retrieve knowledge quickly.

## Project Repository

The source code is hosted at `lailai0916/lailai0916.github.io` on GitHub.

## Setup

<Steps>
  <Step title="Install Node.js">
    Docusaurus requires Node.js 18 or later. Verify your version before proceeding.

    ```bash
    node --version
    ```
  </Step>
  <Step title="Create a new Docusaurus project">
    Run the scaffolding command in your terminal. Replace `my-website` with your preferred directory name. TypeScript is recommended over JavaScript because it is a strict superset with stronger tooling support.

    ```bash
    npx create-docusaurus@latest my-website classic --typescript
    ```

    The command produces output like this:

    ```text
    [INFO] Creating new Docusaurus project...
    [INFO] Installing dependencies with npm...
    [SUCCESS] Created my-website.
    [INFO] Inside that directory, you can run several commands:

      `npm start`
        Starts the development server.

      `npm run build`
        Bundles your website into static files for production.

      `npm run serve`
        Serves the built website locally.

      `npm run deploy`
        Publishes the website to GitHub pages.
    ```
  </Step>
  <Step title="Start the local development server">
    Change into the project directory and start the server.

    ```bash
    cd my-website
    npm start
    ```

    Docusaurus will open `http://localhost:3000` in your browser automatically. The default Docusaurus welcome page confirms the setup is working.
  </Step>
  <Step title="Build for production">
    When you are ready to publish, generate the static output files.

    ```bash
    npm run build
    ```
  </Step>
  <Step title="Deploy to GitHub Pages">
    Initialize a Git repository, push to GitHub, and configure Docusaurus for your domain.

    ```bash
    git init
    git add .
    git commit -m "Initial commit"
    git branch -M main
    git remote add origin https://github.com/username/my-website.git
    git push -u origin main
    ```

    In `docusaurus.config.ts`, set the `url` and `baseUrl` fields:

    ```ts
    url: 'https://username.github.io',
    baseUrl: '/my-website/',
    ```

    Then deploy:

    ```bash
    npm run deploy
    ```

    After deployment completes, the site is available at `https://username.github.io/my-website/`.
  </Step>
</Steps>

## Plugins

The following plugins are configured in the `plugins` section of `docusaurus.config.ts`:

- **plugin-ideal-image** — Generates responsive, lazy-loaded images with low-quality placeholders.
- **plugin-client-redirects** — Creates client-side page redirects for moved or renamed pages.
- **plugin-google-gtag** — Integrates Google Analytics for traffic and usage analysis.
- **plugin-pwa** — Adds Progressive Web App support with offline mode and installability.
- **remark-plugin-npm2yarn** — Converts `bash npm2yarn` code blocks into tabbed views showing npm, yarn, and pnpm equivalents.

## Website Features

The site includes several built-in capabilities from Docusaurus and its integrations:

- **Markdown and KaTeX** — Write content in Markdown with full math formula rendering.
- **Full-text search** — Powered by Algolia DocSearch for fast, accurate content discovery.
- **Light and dark mode** — Theme toggle with system preference detection.
- **Custom React components** — Embed interactive components directly in Markdown files.
- **Responsive layout** — Optimized for both desktop and mobile viewports.
- **Multilingual support** — Built-in internationalization infrastructure.
- **Version management** — Support for multiple documentation versions.
- **SEO enhancements** — Built-in sitemap generation, meta tags, and Open Graph support.
