LaTeX is a typesetting system widely used for writing documents that contain mathematical formulas. In the browser, [KaTeX](https://katex.org) — a fast JavaScript rendering library — interprets LaTeX syntax and renders it as formatted mathematics. lailai's Home uses KaTeX for all math notation in documentation, notes, and contest solutions.

Recommended tools for writing LaTeX: [Overleaf](https://www.overleaf.com) (collaborative online editor) and [在线 LaTeX 公式编辑器](https://www.latexlive.com) (formula-only editor).

<Note>
  This guide covers syntax rules only. Formatting and typographic conventions for math in text are covered in the [Writing Guide](/project/guides/writing).
</Note>

## Formula Types

### Inline Formula

An inline formula is embedded within a line of text. Wrap the expression with single dollar signs:

```latex
$a^2 + b^2 = c^2$
```

Renders as: $a^2 + b^2 = c^2$ within the surrounding text.

### Display Formula

A display formula appears on its own line, centered, at a larger size. Wrap with double dollar signs on separate lines:

```latex
$$
a^2 + b^2 = c^2
$$
```

<Tip>
  Inline formulas use a compact layout — fractions are smaller, and big-operator limits appear to the side. Use `\displaystyle` inside an inline formula to force the larger display-mode layout.
</Tip>

## Multi-line Environments

### Aligned Equations

Use `aligned` for step-by-step derivations with alignment on the `=` sign:

```latex
\begin{aligned}
  f(x) &= (a + b)^2 \\
       &= a^2 + 2ab + b^2
\end{aligned}
```

$$
\begin{aligned}
  f(x) &= (a + b)^2 \\
       &= a^2 + 2ab + b^2
\end{aligned}
$$

### Piecewise Functions

Use `cases` for piecewise definitions:

```latex
f(x) =
\begin{cases}
  a & x > 0 \\
  b & x = 0 \\
  c & x < 0
\end{cases}
```

$$
f(x) =
\begin{cases}
  a & x > 0 \\
  b & x = 0 \\
  c & x < 0
\end{cases}
$$

### Linear Systems

```latex
\begin{cases}
  a_1 x + b_1 y = c_1 \\
  a_2 x + b_2 y = c_2
\end{cases}
```

$$
\begin{cases}
  a_1 x + b_1 y = c_1 \\
  a_2 x + b_2 y = c_2
\end{cases}
$$

### Arrays

Use `array` for general multi-line blocks. Set alignment per column with `l` (left), `c` (center), or `r` (right):

```latex
\begin{array}{l}
  \cos^2\alpha + \sin^2\alpha = 1 \\
  \sin 2\alpha = 2\sin\alpha\cos\alpha
\end{array}
```

## Style Conventions

The following rules apply to math in lailai's documentation:

- Use `\times` or `\cdot` for multiplication — not `*`.
- Use `\frac` for fractions — not `\dfrac`.
- Use `\dots` for horizontal ellipsis — not `\cdots` or `\ldots`.
- Use `\vdots` for vertical ellipsis and `\ddots` for diagonal ellipsis.
- Use `\operatorname{...}` for custom function names: `\operatorname{lca}`, `\operatorname{gcd}`.
- Use `\mathrm{...}` for physical units: $\mathrm{m/s^2}$, $\mathrm{km}$.
- Use `\mathbb{...}` for number sets: $\mathbb{R}$, $\mathbb{Z}$, $\mathbb{N}$.
- Use `\varnothing` for the empty set — not `\emptyset`.
- Use `\left(` and `\right)` to auto-size brackets around tall expressions.
- Place display formula delimiters (`$$`) on their own lines.
- Do not embed formulas inside headings, bold text, italics, or links.
