## macOS — System Utilities

<CardGroup cols={2}>
  <Card title="CleanMyMac" icon="trash-2">
    System cleaner and optimizer. Handles junk file removal, malware scanning, app uninstallation (complete, including leftover files), and performance monitoring. A practical tool for keeping macOS running efficiently.

    **Price:** ¥588
    **Website:** [macpaw.com/cleanmymac](https://macpaw.com/cleanmymac)
  </Card>
  <Card title="Parallels Desktop" icon="monitor">
    The best virtual machine solution for Mac. Run Windows and Linux alongside macOS with excellent performance — especially on Apple Silicon, where it uses ARM Windows natively. Coherence mode lets Windows apps appear as native Mac windows.

    **Price:** Standard — $100; Pro — $120/year
    **Website:** [parallels.com](https://www.parallels.com)
  </Card>
  <Card title="MenubarX" icon="layout">
    A menubar browser that pins any web page as a persistent floating window, accessible from the menu bar like a native app. Useful for keeping dashboards, messaging apps, or tools always accessible without cluttering the Dock.

    **Price:** Pro — $4.99
    **Website:** [menubarx.app](https://menubarx.app)
  </Card>
  <Card title="AlDente" icon="battery-charging">
    Battery management for MacBook. Caps the maximum charge percentage to protect long-term battery health. If you frequently work plugged in, limiting charge to 80% can significantly extend battery lifespan over years.

    **Price:** ¥65/year; ¥139 perpetual
    **Website:** [apphousekitchen.com/aldente-overview](https://apphousekitchen.com/aldente-overview/)
  </Card>
  <Card title="Vivid" icon="sun">
    Unlocks the full HDR brightness of MacBook Pro and Pro Display XDR screens — up to 1600 nits — even outside of HDR content. Particularly useful in bright outdoor environments.

    **Price:** ¥29
    **Website:** [getvivid.app](https://www.getvivid.app)
  </Card>
  <Card title="Macs Fan Control" icon="cpu">
    Real-time monitoring and manual control of Mac fan speeds. Useful for keeping the system cool during extended sessions or reducing fan noise when noise is the priority.

    **Price:** ¥88
    **Website:** [crystalidea.com/macs-fan-control](https://crystalidea.com/macs-fan-control)
  </Card>
</CardGroup>
