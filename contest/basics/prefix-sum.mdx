Prefix sums are one of the highest-leverage techniques in competitive programming: with $O(n)$ preprocessing, you can answer any range sum query in $O(1)$. The same idea extends to two dimensions, and its inverse — the difference array — turns range updates into $O(1)$ operations. Recognizing when to apply these techniques often transforms an $O(nq)$ brute force into a clean $O(n + q)$ solution.

## 1D prefix sums

Given an array $A$ of length $n$, define the prefix sum array $S$ as:

$$S_k = \sum_{i=1}^{k} A_i = A_1 + A_2 + \cdots + A_k, \quad S_0 = 0$$

A range sum query $\sum_{i=l}^{r} A_i$ then becomes:

$$\sum_{i=l}^{r} A_i = S_r - S_{l-1}$$

This reduces any number of range sum queries from $O(n)$ each to $O(1)$ after $O(n)$ preprocessing.

```cpp prefix-sum-1d.cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<long long> a(n + 1), s(n + 1, 0);
    for (int i = 1; i <= n; i++) cin >> a[i];

    // Build prefix sum: O(n)
    for (int i = 1; i <= n; i++)
        s[i] = s[i - 1] + a[i];

    // Answer each query in O(1)
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << s[r] - s[l - 1] << '\n';
    }
    return 0;
}
```

<Note>
Use 1-indexed arrays for prefix sums so that $S_0 = 0$ provides a clean base case. This avoids special-casing $l = 1$ in every query.
</Note>

## 2D prefix sums

For a 2D grid $A$ of size $n \times m$, define:

$$S[i][j] = \sum_{r=1}^{i} \sum_{c=1}^{j} A[r][c]$$

Built using the inclusion-exclusion identity:

$$S[i][j] = A[i][j] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]$$

A rectangular range sum query over rows $[r_1, r_2]$ and columns $[c_1, c_2]$ is then:

$$\text{sum} = S[r_2][c_2] - S[r_1-1][c_2] - S[r_2][c_1-1] + S[r_1-1][c_1-1]$$

```cpp prefix-sum-2d.cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
long long a[MAXN][MAXN], s[MAXN][MAXN];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, q;
    cin >> n >> m >> q;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            cin >> a[i][j];

    // Build 2D prefix sum: O(n*m)
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            s[i][j] = a[i][j] + s[i-1][j] + s[i][j-1] - s[i-1][j-1];

    // Answer each rectangle query in O(1)
    while (q--) {
        int r1, c1, r2, c2;
        cin >> r1 >> c1 >> r2 >> c2;
        cout << s[r2][c2] - s[r1-1][c2] - s[r2][c1-1] + s[r1-1][c1-1] << '\n';
    }
    return 0;
}
```

<Tip>
The 2D formula has four terms and three minus/plus signs — memorize it as "big rectangle minus two side strips plus the doubly-subtracted corner."
</Tip>

## Difference arrays — range updates in O(1)

A difference array $D$ is the inverse of prefix sums. Define $D_i = A_i - A_{i-1}$ (with $D_1 = A_1$). The original array is recovered by taking prefix sums of $D$:

$$A_i = \sum_{j=1}^{i} D_j$$

The key insight: adding $v$ to every element in the range $[l, r]$ requires only two updates to $D$:

$$D_l \mathrel{+}= v, \quad D_{r+1} \mathrel{-}= v$$

After all range updates, recover the final array with one prefix sum pass.

```cpp difference-array.cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<long long> a(n + 2, 0), d(n + 2, 0);
    for (int i = 1; i <= n; i++) cin >> a[i];

    // Initialize difference array from a[]
    for (int i = 1; i <= n; i++)
        d[i] = a[i] - a[i - 1];

    // Apply range updates: O(1) each
    while (q--) {
        int l, r;
        long long v;
        cin >> l >> r >> v;
        d[l] += v;
        d[r + 1] -= v;
    }

    // Recover final array: O(n)
    for (int i = 1; i <= n; i++) {
        d[i] += d[i - 1];  // prefix sum of d gives the updated a[]
        cout << d[i] << " \n"[i == n];
    }
    return 0;
}
```

<Note>
Difference arrays assume you apply all updates before any queries. If you need to interleave updates and range sum queries, use a **Fenwick tree** (Binary Indexed Tree) or **segment tree** instead.
</Note>

## 2D difference arrays

For 2D grids with rectangle range updates (add $v$ to every cell in rows $[r_1, r_2]$, columns $[c_1, c_2]$), extend the idea to two dimensions:

```cpp difference-array-2d.cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
long long d[MAXN][MAXN];

// Range update: add v to rectangle [r1,c1] x [r2,c2]
void update(int r1, int c1, int r2, int c2, long long v) {
    d[r1][c1] += v;
    d[r1][c2 + 1] -= v;
    d[r2 + 1][c1] -= v;
    d[r2 + 1][c2 + 1] += v;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, q;
    cin >> n >> m >> q;

    while (q--) {
        int r1, c1, r2, c2; long long v;
        cin >> r1 >> c1 >> r2 >> c2 >> v;
        update(r1, c1, r2, c2, v);
    }

    // Recover grid with two prefix sum passes
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            d[i][j] += d[i-1][j] + d[i][j-1] - d[i-1][j-1];

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++)
            cout << d[i][j] << " \n"[j == m];
    }
    return 0;
}
```

## Standard library support

The C++ STL provides these algorithms for related operations:

- [`std::partial_sum`](https://en.cppreference.com/w/cpp/algorithm/partial_sum) — computes prefix sums into an output range
- [`std::adjacent_difference`](https://en.cppreference.com/w/cpp/algorithm/adjacent_difference) — computes differences (inverse of partial_sum)

```cpp stl-prefix.cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> a = {1, 3, 2, 5, 4};
    vector<int> s(a.size());

    // prefix sums: s = {1, 4, 6, 11, 15}
    partial_sum(a.begin(), a.end(), s.begin());

    // difference array: back to a
    vector<int> d(s.size());
    adjacent_difference(s.begin(), s.end(), d.begin());
    // d = {1, 3, 2, 5, 4}  (same as original a)
}
```

## Technique summary

| Technique | Preprocessing | Query | Update | Use when |
|---|---|---|---|---|
| 1D prefix sum | $O(n)$ | $O(1)$ range sum | Rebuild $O(n)$ | Static array, many range sums |
| 2D prefix sum | $O(nm)$ | $O(1)$ rect sum | Rebuild $O(nm)$ | Static grid, many rect sums |
| Difference array | $O(n)$ | $O(n)$ after all updates | $O(1)$ range add | Batch range updates, then read |
| 2D difference | $O(nm)$ | $O(nm)$ after all updates | $O(1)$ rect add | Batch rect updates, then read |
